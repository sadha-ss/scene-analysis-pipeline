# Scene Analysis Project

## Files
- `scene_analysis.ipynb`: main Jupyter Notebook with explanations, visualisations, experiments, and examples.
- `scene_analysis.py`: reusable Python implementation.
- `requirements.txt`: dependencies.

## Run
1. Extract the project folder.
2. Open a terminal in this folder.
3. Install dependencies: `python -m pip install -r requirements.txt`
4. Start Jupyter: `jupyter notebook`
5. Open `scene_analysis.ipynb` and run cells from top to bottom.

The notebook trains on a generated synthetic dataset. It is a practical implementation
of a classical, inspectable pipeline; it does not claim to reproduce any external
reported metrics. The synthetic model is not a general-purpose detector for photographs.
